# 顶级能源管理平台生态系统

**SaaS产品与开源GitHub项目精选列表**
*聚焦公用事业账单管理、能源智能、建筑自动化与可持续发展报告*
**最后更新：2026年9月**

本仓库追踪**能源管理**领域的知名**SaaS平台**和**开源项目**。这些工具帮助设施管理者、能源经理和可持续发展团队集中管理公用事业账单，监控能源消耗，优化建筑运营，并报告碳排放数据。

**示例**包括 EnergyCAP、Dexma by Spacewell、GridPoint、Enertiv、WatchWire、Schneider EcoStruxure Resource Advisor、Measurabl、Verdigris、BrainBox AI 和 Energy Elephant（该领域的领先者）。

**开源重点**：本节大幅扩展了所有主要的活跃项目，用于自托管、自定义数据管道和透明的能源数据管理——非常适合希望完全控制其公用事业和可持续发展数据、而不受昂贵 SaaS 订阅限制的设施团队和能源经理。

## SaaS/托管平台

- **[EnergyCAP](https://www.energycap.com/)**
  公用事业账单管理和能源管理平台，服务超过 40 年。集中管理电、气、水、下水道等多种公用事业数据，提供自动账单审计（每 5 张账单中识别出 1 张错误）、成本分摊、预算和基准比较。服务 26,000+ 用户，年追踪账单价值超 $100B 。

- **[Dexma by Spacewell](https://www.dexma.com/)**
  能源智能平台，帮助 ESCO、能源供应商和大型企业优化能源效率。支持 150+ 数据源，实时监控、成本分摊、基准比较和自动化报告。2020 年加入 Spacewell（Nemetschek 集团），服务 10,000+ 组织 。

- **[GridPoint](https://www.gridpoint.com/)**
  商业建筑能源管理系统，连接建筑、企业和电网。分析 HVAC 和照明数据以优化能源使用，降低成本和碳排放。客户包括 Wendy's 等连锁品牌 。

- **[Enertiv](https://www.enertiv.com/)**
  AI 驱动的商业地产能源管理平台。提供公用事业数据采集与验证、设备级能源监控、租户计费、碳规划和预防性维护解决方案。通过 QR 码数字化设备库存，移动应用支持运维团队 。

- **[WatchWire](https://info.watchwire.ai/)**
  可持续发展与能源管理软件（2023 年被 Tango Analytics 收购）。追踪能源、水、废弃物和排放数据，提供 API、M&V 项目管理、预算和账单模拟。客户包括 Brookfield 。

- **[Schneider EcoStruxure Resource Advisor](https://www.se.com/)**
  施耐德电气的企业级能源与可持续发展数据平台。集中 400+ 数据流，管理能源采购、碳排放、公用事业账单和可持续发展报告。Resource Advisor Copilot 提供 AI 驱动的数据分析 。

- **[Measurabl](https://www.measurabl.de/)**
  房地产 ESG 数据管理平台。与 S&P Global 合作提供独立 ESG 验证，支持 GRESB 报告，集成 PG&E 和 PERSE 公用事业数据。Data Manager 功能自动识别数据缺口和异常值 。

- **[Verdigris](https://verdigris.co/)**
  AI 驱动的建筑能源监控平台。使用自有硬件和软件，通过非侵入式负载 disaggregation 识别设备签名、检测设备故障和优化峰值用电。兼容 BACnet/IP 和 Modbus/TCP 。

- **[BrainBox AI](https://www.tranetechnologies.com/)**
  自主 AI 建筑能源管理解决方案（被 Trane Technologies 收购）。通过 AI 持续优化 HVAC 系统，案例包括 Dollar Tree 600 家门店年省 800 万 kWh 和 $100 万，迪拜 Meera Tower HVAC 能耗降低 42.7% 。

- **[Energy Elephant](https://energyelephant.com/)**
  跨国公司和供应链能源管理工具。集中全球公用事业账单、智能电表和传感器数据，管理远程员工和 Scope 3 排放。支持 TCFD、CDP 和 ISO 50001 报告 。

## 开源GitHub项目

- **[OpenEMS](https://github.com/OpenEMS/openems)**
  开源能源管理系统，由 OpenEMS 协会驱动，FENECON GmbH 发起。采用模块化架构，支持快速 PLC 级设备控制、可复用设备无关控制算法、广泛的设备与协议支持。包含 OpenEMS Edge（现场设备）和 OpenEMS Backend（云端聚合监控）。Eclipse Public License 2.0 。

- **[ecosysnc](https://github.com/kimdain0222/ecosysnc)**
  智能建筑能源管理系统（SBEMS）创业项目。分析建筑电力使用数据，开发空置率预测模型，实现空置时自动控制照明/空调。技术栈：React.js 前端、FastAPI 后端、PostgreSQL 数据库、Python ML 管道 。

- **[Smart Building IIoT Framework](https://github.com/hashiniWijerathne/e17-co326-Smart-Building)**
  基于 MQTT 和 SCADA 的智能建筑框架。涵盖 HVAC、照明、安全、能源使用、占用控制、光伏和整体控制系统。使用 Mosquitto MQTT Broker、Arduino/ESP32 设备、开源 SCADA 和分析平台 。

- **[SustainML](https://github.com/SustainML/SustainML)**
  可持续性机器学习框架（搜索结果中提及但未提供完整详情）。用于构建能源和可持续发展领域的机器学习应用。

### 其他强开源选项

- **能源管理框架**：**OpenEMS**（德国 FENECON 支持，生产级）、**ecosysnc**（创业原型，AI-IoT 集成）。
- **智能建筑**：**Smart Building IIoT Framework**（MQTT + SCADA 开源实现）。
- **数据分析与建模**：MATLAB/Simulink 可持续发展项目中心提供绿色氢能、风电预测性维护等技术经济评估模型 。

**构建自定义系统的框架**：结合 **OpenEMS** 用于设备控制和数据聚合，**ecosysnc** 或 **Smart Building IIoT Framework** 用于建筑级监控，**PostgreSQL + TimescaleDB** 用于时序数据存储，**Grafana** 用于可视化。添加 **MQTT**（Mosquitto）用于设备通信和 **FastAPI** 用于 API 层。
